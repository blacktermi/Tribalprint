# Tribalprint React

Migration progressive du site statique Tribalprint vers une application React (Vite + TypeScript + Tailwind).

Démarrer:
- npm install
- npm run dev

Structure initiale:
- Layout avec entête/footers
- Routes: / (Home), /a-propos

Prochaines étapes: porter les pages clés (produits) et intégrer la navigation complète.
